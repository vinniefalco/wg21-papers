# Code review: P4195 build script

Reviewed the untracked `build.py`, `test_build.py`, and `fixtures/` under `research/p4195/support/` in wg21-papers against the `build-script-spec` block of the support kit, by reading only (`git diff` is empty; the whole folder is untracked). Nine findings.

1. **build.py, `run_checks` (spec gap).** Check 1 only sees citations collected from items, tables, and the front and appendix files, so a citation on a prose line such as an `In plain terms:` recap is never tested for an undefined key. `render` then copies that line into the emitted file with its raw key, so the defect passes every check silently. | fixed: `build_proof` now collects citations on prose and heading lines into their source, and check 1 tests them for undefined keys. They do not count toward check 5, since a prose line is not a proof item, and emit still copies prose lines unchanged as the spec says. A recap on line 6 of `fixtures/fail-1.md` covers it.

2. **build.py, `inflections` (spec gap).** Forms are built by adding suffixes to the listed spelling, so `gaming` yields `gamings` and `gaminged` but never the past tense `gamed`. A sentence like "the poll was gamed" passes check 7 even though the spec says past tenses match. | fixed: `inflections` now forms the past tense of a listed -ing word from its stem, so `gaming` yields `gamed`. `game` and `games` stay unmatched so phrases like "game theory" are not flagged. Line 7 of `fixtures/fail-7.md` covers it.

3. **build.py, `forbidden` (beyond spec).** On its default `cites=True` path, used for items, tables, and the front and appendix files, it blanks out citations and `{#...}` key markers before matching, an exemption that check 7 in the spec does not list. Line 7 of `fixtures/fail-7.md` and `test_check_7_forbidden_strings` lock the exemption in. | fixed: removed the exemption. `forbidden` no longer blanks citations or `{#...}` markers, so keys and cited keys are checked like other text. `fixtures/fail-7.md` now expects "carry" on the `l:carry-rule` marker (line 8) and on the citation that names it (line 17).

4. **build.py, `ELLIPSIS_RE` (beyond spec).** Check 6 splits Fact quotes at the Unicode ellipsis character as well as at `...`, which the spec does not say. `rules-extract.md` contains no such character, so this only loosens check 6, and no test covers it. | fixed: removed `ELLIPSIS_RE`; Fact quotes now split only at `...`, as the spec says. Line 5 of `fixtures/fail-6.md` shows a quote with a Unicode ellipsis failing check 6.

5. **test_build.py, `BuildTests` (untested).** No test exercises the labels option, the dependents option and its transitive walk in `dependents`, or the literal `check` token that `main` strips from the source list. Any of these could break with every test still passing. | fixed: added `test_labels_continue_across_sources`, `test_dependents_follow_citations_transitively` (two keys, an indirect chain, and an undefined key), and `test_check_token_is_not_a_source` (the token is dropped, and alone it leaves no sources).

6. **test_build.py, `BuildTests` (untested).** Every test passes a single SOURCE file and no fixture has more than one table. Numbering top-level items continuously across files in `build_proof`, labels from Table 2 onward, and the blank line `render_proof` inserts between sources therefore have no test. | fixed: added `fixtures/proof-2.md`, which opens with a list item and holds a second table. The labels test and the emit test now pass `proof.md` and `proof-2.md`, so items 12 to 14, Table 2, and the blank line between sources are all checked; `expected.md` gained the second source. Dropping the between-sources blank now fails the emit test.

7. **test_build.py, `BuildTests` (untested).** Several sub-rules in `run_checks` have no failing case: check 1 on an undefined key cited by the front or appendix file, front and appendix citations not counting toward check 5, the `m:` and `t:` orphan exemptions, and check 7 on table captions. Removing any one of them would leave every test green. | fixed: the check 1 test adds `fail-1-front.md` and `fail-1-appendix.md`, each citing an undefined key. The check 5 test adds `fail-5-front.md` and `fail-5-appendix.md` citing the two orphans, which stay orphans. `fail-5.md` adds an uncited `m:` remark, an uncited `t:` table, and a recap citing an orphan; the orphan loop now walks every unit, so the `t:` exemption is what spares tables, and dropping either exemption fails the test. `fail-7.md` gives the table caption a forbidden word.

8. **test_build.py, `BuildTests` (untested).** No fixture is malformed, so none of the format errors raised in `parse`, `close`, and `citations` has a test, including bad marker indentation, a missing or malformed key, a nested item with no parent, an unterminated table, and a citation split across lines. | fixed: added `fixtures/malformed.md` and `test_format_errors`, which cover every format error message: bad marker indentation, an item with no key, a malformed key, an indented line after a key, a split citation, an empty citation key, a stray key marker, a nested item with no parent, a malformed caption, a caption with no table, and an unterminated table.

9. **build.py, `Item` and `Table` (dead code).** `Item.weakened` (set in `close`), `Item.indent`, and the class attribute `Table.parent` are assigned but never read. | fixed: removed all three; `close` still accepts `{#KEY weakened}`.
